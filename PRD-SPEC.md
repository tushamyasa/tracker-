# Часть I. PRD (что и зачем)

## 1. Цель продукта

Веб-приложение, в котором человек быстро записывает тренировки в зале, видит прогресс по весам, объёму и частоте и получает мотивацию продолжать.

## 2. Целевая аудитория

- Новички и любители силовых тренировок, которые ведут записи в заметках или таблицах.
- Основной сценарий: телефон в руке между подходами, 2–3 тапа на подход.

## 3. Задачи пользователя (Jobs to be done)

1. Записать подход за несколько секунд, не теряя ритм тренировки.
2. Видеть, что я делал в прошлый раз, и побить это.
3. Видеть, растёт ли сила, и получать за это награды.
4. Иметь готовый план тренировок на неделю.

## 4. Границы версии 1 (MVP)

Входит: авторизация по email, каталог упражнений, шаблоны тренировок, запись тренировки с таймером отдыха, история, прогресс и личные рекорды, замеры тела, календарь и недельная цель, геймификация, тема и два языка, экспорт данных.

Не входит: социальная часть (друзья, лента), платежи и подписки, нативные приложения, интеграции с часами и Apple Health, ИИ-тренер, питание.

## 5. Функциональные требования

Приоритеты: P0 — обязательно в MVP, P1 — желательно в MVP, P2 — после MVP.

### 5.1 Авторизация (P0)
- FR-A1. Вход по email без пароля и без подтверждения. Принимается любой синтаксически корректный адрес, в том числе вымышленный (например, `test@test.com`).
- FR-A2. Если email новый — аккаунт создаётся автоматически, показывается короткий онбординг. Если известен — открывается существующий.
- FR-A3. Сессия хранится в защищённом cookie и действует 30 дней. Выход — из профиля.
- FR-A4. Удаление аккаунта и всех данных из профиля.

Пояснение: поскольку email не подтверждается, любой, кто знает адрес, получает доступ к аккаунту. Это осознанное решение для демо/личного использования. В production-версии нужна проверка владения почтой.

### 5.2 Онбординг и профиль (P0)
- FR-P1. Имя, цель (сила / масса / выносливость / здоровье), опыт, частота тренировок в неделю (становится недельной целью).
- FR-P2. Единицы: кг/фунты, см/дюймы. Язык: ru/en. Тема: авто/светлая/тёмная.
- FR-P3. Переключатель эффектов (конфетти).

### 5.3 Каталог упражнений (P0)
- FR-E1. Стартовая база из 100+ упражнений: название (ru/en), группа мышц, оборудование, фото/GIF, краткое описание техники.
- FR-E2. Поиск по названию, фильтры по группе мышц и оборудованию.
- FR-E3. Свои упражнения: создание, редактирование, удаление, загрузка своего фото.
- FR-E4. Избранное (P1).
- FR-E5. Карточка упражнения: техника, личный рекорд, график прогресса, история подходов.
- Тип упражнения определяет поля подхода: вес × повторы (по умолчанию), только повторы (собственный вес), время (планка), вес × время.

### 5.4 Шаблоны и программы (P0 / P1)
- FR-T1. Создать шаблон тренировки: название, список упражнений с целевыми подходами и повторами, порядок (drag-and-drop или кнопки вверх/вниз).
- FR-T2. Дублировать, редактировать, удалять шаблон.
- FR-T3. Готовые стартовые шаблоны: Full Body, Push/Pull/Legs, Upper/Lower (P1).
- FR-T4. Расписание недели: привязка шаблонов к дням недели, на главной «Сегодня по плану» (P1).

### 5.5 Запись тренировки (P0)
- FR-W1. Старт из шаблона или пустой тренировки. Только одна активная тренировка одновременно.
- FR-W2. Экран тренировки: список упражнений, для каждого подходы со значениями «прошлый раз» (подсказка) и полями вес/повторы, отметка «выполнен».
- FR-W3. Добавление подхода, удаление подхода, типы подхода: рабочий, разминочный, до отказа (P1).
- FR-W4. Добавление упражнения в процессе, замена, пропуск.
- FR-W5. Таймер отдыха стартует автоматически после выполненного подхода, длительность по умолчанию настраивается, можно +15 / −15 с, звук и вибрация (P1).
- FR-W6. Общий секундомер тренировки. (Сохранение тренировки как шаблона и копирование — FR-L9.)
- FR-W7. Заметка к тренировке и к упражнению; оценка самочувствия 1–5 после завершения (P1).
- FR-W8. Автосохранение черновика: закрытие вкладки или обновление страницы не теряет введённое.
- FR-W9. Завершение: итоговая сводка (длительность, объём, число подходов, новые рекорды, полученные XP и достижения).
- FR-W10. Возможность отменить активную тренировку и добавить прошедшую тренировку задним числом.

### 5.6 История (P0)
- FR-H1. Список завершённых тренировок с датой, названием, длительностью, объёмом.
- FR-H2. Просмотр деталей, редактирование задним числом, удаление, повтор тренировки одним тапом.
- FR-H3. Фильтр по периоду и по упражнению.

### 5.7 Прогресс и аналитика (P0)
- FR-G1. Личные рекорды по упражнению: максимальный вес, максимум повторов, лучший объём подхода, расчётный 1RM (формула Эпли).
- FR-G2. Линейные графики по упражнению: вес, расчётный 1RM, объём. Периоды 1 мес / 3 мес / 6 мес / год / всё.
- FR-G3. Календарь-теплокарта активности за 12 месяцев.
- FR-G4. Недельный и месячный объём, число тренировок, распределение нагрузки по группам мышц (P1).
- FR-G5. Определение рекорда в момент записи подхода.

### 5.8 Замеры тела (P1)
- FR-B1. Вес тела, процент жира (необязательно), обхваты (грудь, талия, бёдра, руки).
- FR-B2. График по каждому показателю, заметки. Фото прогресса — см. FR-V4.

### 5.9 Геймификация (P0 / P1)
- FR-X1. Серия дней: считается по неделям с выполненной недельной целью или по дням с тренировкой (правило фиксируется в разделе 8).
- FR-X2. XP и уровни. Начисление: подход +10, тренировка +50, рекорд +100.
- FR-X3. Достижения (не менее 15), экран с витриной, уведомление при получении.
- FR-X4. Недельная цель с прогресс-кольцом.
- FR-X5. Конфетти и золотая плашка PR при рекорде (можно отключить).

### 5.10 Интерфейс и настройки (P0)
- FR-U1. Mobile-first, адаптивность до десктопа.
- FR-U2. Светлая/тёмная тема, русский/английский.
- FR-U3. Экспорт всех данных в CSV и JSON; импорт JSON (P2).
- FR-U4. PWA и офлайн-режим — см. FR-V6.

### 5.11 Расширенная запись тренировки (вдохновлено Hevy и Strong)
Дополняет 5.5. Ничего из 5.5 не дублируется.
- FR-L1. Суперсеты и круговые блоки: объединение 2+ упражнений в группу, таймер отдыха запускается после последнего упражнения группы (P0).
- FR-L2. Тип подхода «дроп-сет» (к уже имеющимся рабочий, разминочный, до отказа) (P1).
- FR-L3. RPE (6–10) или RIR для подхода, переключается в настройках (P1).
- FR-L4. Индивидуальный таймер отдыха для каждого упражнения (переопределяет общий из профиля) (P1).
- FR-L5. Калькулятор блинов: ввод целевого веса, выбор грифа и набора блинов, подсказка «на сторону: 20 + 10 + 2.5». Наличие блинов и вес грифа настраиваются в профиле (P0).
- FR-L6. Калькулятор разминки: из рабочего веса предлагает 3–4 разминочных подхода, добавляет их в тренировку одним тапом (P1).
- FR-L7. Закреплённая заметка к упражнению (настройка стойки, высота скамьи), показывается при каждой тренировке (P1).
- FR-L8. Кардио и дистанционные упражнения: тип «дистанция + время», расчёт темпа и скорости (P1).
- FR-L9. Копирование предыдущей тренировки в новую и сохранение любой тренировки как шаблона (P0).
- FR-L10. Сохранение экрана тренировки открытым (Wake Lock API) и уведомление таймера отдыха, когда вкладка в фоне (P1).
- FR-L11. Отдельный калькулятор 1RM по весу и повторам (P2).

### 5.12 Планировщик (вдохновлено планировщиками тренировок)
Дополняет шаблоны и недельное расписание 5.4 (FR-T4). Эти функции не повторяют его.
- FR-S1. Календарь планов: планирование тренировки на конкретную дату (разово), перенос и отмена; на календаре видны плановые и выполненные тренировки (P0).
- FR-S2. Программы на несколько недель: набор шаблонов по дням на 4–12 недель, номер текущей недели, автоматический переход к следующей тренировке программы (P1).
- FR-S3. Правила прогрессии в программе: «+2.5 кг за неделю» или двойная прогрессия (повторы в диапазоне, затем вес) (P1).
- FR-S4. Неделя разгрузки (deload): отметка в программе, веса снижаются на заданный процент (P2).
- FR-S5. Дни отдыха как явный тип события; предупреждение, если запланировано больше N тренировок подряд (P2).
- FR-S6. Напоминания о тренировке: браузерные push-уведомления в выбранное время (P2).
- FR-S7. Папки для шаблонов и программ (Push / Pull / Legs и т. п.) (P1).

### 5.13 Статистика и аналитика (вдохновлено разделами статистики приложений)
Дополняет 5.7. Базовые рекорды и графики упражнения (FR-G1…G5) не повторяются.
- FR-D1. Анатомическая схема тела с подсветкой групп мышц по нагрузке за выбранный период (P1).
- FR-D2. Сводки: неделя, месяц, год, всё время; сравнение с предыдущим периодом в процентах (P1).
- FR-D3. Лента рекордов: хронологический список всех PR с фильтром по упражнению (P0).
- FR-D4. Стандарты силы: уровень (новичок / средний / продвинутый) по основным базовым упражнениям относительно веса тела (P2).
- FR-D5. Тренды: средняя длительность тренировки, число подходов за тренировку, соотношение push/pull (P1).
- FR-D6. Регулярность: процент выполненных плановых тренировок, самые частые дни, средний перерыв между тренировками (P1).
- FR-D7. Недельный отчёт (экран и по желанию письмо-копия на email) (P2).
- FR-D8. Цели: целевой вес на упражнении или целевой вес тела с прогрессбаром и прогнозом даты достижения (P1).
- FR-D9. Рекомендация следующего веса по истории подходов (P1).

### 5.14 Продвинутые функции
- FR-V1. Карточка для шеринга: картинка с итогами тренировки или рекорда, скачивание или Web Share API (P1).
- FR-V2. Импорт истории из CSV других приложений (Hevy, Strong) с сопоставлением упражнений (P1).
- FR-V3. Теги и фильтры тренировок («дом», «зал», «дедлифт-день») (P2).
- FR-V4. Фото прогресса с датами и сравнением «до / после» (P2).
- FR-V5. Режим «зал»: упрощённый экран с увеличенными цифрами и одной кнопкой «Подход выполнен» (P1).
- FR-V6. PWA и офлайн-режим активной тренировки с синхронизацией при появлении сети (P1, было P2 в FR-U4).
- FR-V7. Публичная ссылка на тренировку (только чтение, отключается в профиле) (P2).

### 5.15 Сводка по приоритетам
- P0: авторизация, профиль, каталог, шаблоны, запись тренировки, история, прогресс и PR, геймификация (базовая), суперсеты, калькулятор блинов, копирование тренировки, календарь планов, лента рекордов.
- P1: замеры, расширенные подходы (дроп, RPE, разминка, кардио), программы, прогрессия, анатомическая схема, сравнение периодов, цели, рекомендации веса, шеринг, импорт CSV, режим «зал», PWA.

## 6. Нефункциональные требования

| Область | Требование |
|---------|-----------|
| Производительность | LCP < 2.5 с на среднем телефоне по 4G, отклик на ввод подхода < 100 мс |
| Доступность | WCAG 2.1 AA, управление с клавиатуры |
| Безопасность | Подписанные httpOnly cookie, валидация всех входов (zod), защита от CSRF и IDOR: каждый запрос проверяет владельца записи |
| Приватность | Данные пользователя не передаются третьим лицам, аналитика отсутствует в MVP |
| Надёжность | Автосохранение активной тренировки каждые 5 с / при каждом изменении |
| Совместимость | Последние 2 версии Chrome, Safari, Firefox, Edge; iOS Safari 16+ |
| Локализация | ru, en; все строки во внешних словарях |

## 7. Метрики успеха

- 70 % новых пользователей записывают первую тренировку в первую сессию.
- Медиана времени записи подхода < 5 с.
- 40 % активных пользователей выполняют недельную цель.

## 8. Бизнес-правила

- Объём = сумма (вес × повторы) по рабочим и «до отказа» подходам; разминочные не учитываются.
- 1RM (Эпли) = вес × (1 + повторы / 30); при повторах = 1 равен весу. Рассчитывается для подходов 1–12 повторов.
- Рекорд засчитывается, если превышает предыдущий максимум пользователя по данному упражнению и типу рекорда; первая запись упражнения рекордом не считается.
- Серия дней: сохраняется, если между тренировками прошло не больше 2 календарных дней (допускается день отдыха и ещё один пропуск); иначе сбрасывается.
- Уровень N требует суммарно `100 × N × (N + 1) / 2` XP (100, 300, 600, …).
- Все веса хранятся в килограммах, пересчёт в фунты только при отображении.
- Время хранится в UTC, отображается в часовом поясе пользователя.

## 9. Технологический стек

| Слой | Выбор |
|------|-------|
| Фреймворк | Next.js 15 (App Router), React 19, TypeScript (strict) |
| Стили | Tailwind CSS 4 + CSS-переменные из design.md |
| Компоненты | Собственные на базе Radix UI примитивов (диалоги, табы, переключатели), иконки Lucide |
| Графики | Recharts, календарь-теплокарта собственный компонент |
| БД | PostgreSQL + Prisma (локально PGlite: настоящий PostgreSQL в WebAssembly) |
| Авторизация | Собственная: email → upsert пользователя → подписанная сессия (JWT через `jose`, httpOnly cookie). Auth.js не нужен: нет паролей и OAuth |
| Данные | Server Actions для мутаций, серверные компоненты для чтения, TanStack Query на экране активной тренировки |
| Валидация | zod на клиенте и сервере |
| i18n | next-intl, словари ru/en, локаль в cookie |
| Темы | next-themes |
| Анимации | Tailwind transitions, `canvas-confetti` |
| Drag-and-drop | dnd-kit |
| Тесты | Vitest (логика: 1RM, объём, серии, XP), Playwright (E2E ключевых сценариев) |
| Линтеры | ESLint, Prettier |

## 10. Архитектура и структура

```
src/
  app/
    [locale]/
      (auth)/login, onboarding
      (app)/                     # защищённая часть, общий layout с навигацией
        page.tsx                 # Главная
        workouts/                # история, [id], new
        workout/active           # экран активной тренировки
        templates/               # список, редактор
        exercises/               # каталог, [id]
        progress/                # графики, рекорды, теплокарта
        body/                    # замеры
        achievements/
        profile/                 # настройки, экспорт, удаление
    api/export                   # скачивание CSV/JSON
  components/ui, charts, workout, ...
  server/
    auth/session.ts
    actions/                     # Server Actions по доменам
    services/                    # prs.ts, xp.ts, streaks.ts, volume.ts
  lib/                           # utils, units, validators
  messages/ru.json, en.json
prisma/schema.prisma, seed.ts
```

Защита маршрутов: middleware проверяет cookie сессии, неавторизованных перенаправляет на `/login`.

| ProgressPhoto | id, userId, date, url, note |
| ShareLink | id, workoutId, token, enabled |
| Achievement | id, code (unique), tier |
| UserAchievement | userId, achievementId, unlockedAt |

Индексы: `Workout(userId, startedAt)`, `SetEntry(workoutExerciseId)`, `PersonalRecord(userId, exerciseId, type)`, уникальный `User.email`. Ограничение: не более одной `Workout` со статусом `active` на пользователя.

## 13. Экраны

1. **Вход**: поле email, кнопка «Войти». Подсказка, что подойдёт любой email.
2. **Онбординг** (3 шага): имя и цель, опыт и частота, единицы и язык.
3. **Главная**: приветствие, серия, кольцо недельной цели, карточка «Сегодня по плану» с кнопкой «Начать», последняя тренировка, мини-теплокарта.
4. **Активная тренировка**: шапка с секундомером, упражнения с подходами, таймер отдыха (плавающий), кнопки «Добавить упражнение» и «Завершить».
5. **Итог тренировки**: цифры, рекорды, XP, достижения, конфетти.
6. **История** и **деталь тренировки**.
7. **Шаблоны**: список, редактор.
8. **Упражнения**: каталог с поиском и фильтрами, карточка упражнения.
9. **Прогресс**: выбор упражнения, графики, рекорды, теплокарта, объёмы по группам.
10. **Замеры тела**.
11. **Достижения и уровень**.
13. **Календарь**: плановые и выполненные тренировки, перенос перетаскиванием.
14. **Программы**: список, неделя за неделей, правила прогрессии.
15. **Анатомия и аналитика**: схема тела, сводки с сравнением периодов, тренды, регулярность, лента рекордов.
16. **Цели**: список целей с прогнозом.
17. **Импорт и шеринг**: загрузка CSV, карточка для публикации.
12. **Профиль и настройки**: данные, единицы, язык, тема, эффекты, экспорт, выход, удаление аккаунта.

Для каждого экрана: состояния загрузки (skeleton), пусто (empty state с призывом), ошибки (toast + повтор).

## 15. Тестирование и критерии приёмки

Юнит-тесты (Vitest): расчёт объёма, 1RM, определение PR (включая «первая запись не рекорд»), серии, уровни, конвертация единиц.

E2E (Playwright), обязательные сценарии:
1. Вход с вымышленным email создаёт аккаунт; повторный вход открывает тот же аккаунт.
2. Создание шаблона → старт → запись 3 подходов → завершение → тренировка в истории.
3. Обновление страницы посреди активной тренировки не теряет данные.
4. Рекорд помечается PR и появляется в разделе прогресса.
5. Переключение языка и темы сохраняется после перезагрузки.
6. Пользователь A не видит и не может изменить данные пользователя B.
7. Экспорт отдаёт корректный CSV и JSON.

Приёмка MVP: все P0 реализованы, E2E зелёные, Lighthouse mobile: Performance ≥ 85, Accessibility ≥ 95, нет ошибок в консоли на основных экранах.

## 16. Риски и открытые вопросы

| Риск / вопрос | Решение |
|---------------|---------|
| Вход без подтверждения email: захват чужого аккаунта | Принято осознанно; в production добавить magic link |
| Лицензии на фото/GIF упражнений | Использовать открытые наборы с проверенной лицензией или свои иллюстрации |
| Объём медиа и скорость загрузки | `next/image`, WebP, лёгкие превью, ленивая загрузка |
| Оффлайн-режим в зале | Вынесен в P2 (PWA + локальная очередь) |
| Точный список функций из ссылки ChatGPT недоступен | Пользователь проверяет раздел 5 и корректирует приоритеты |
