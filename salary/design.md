# Дизайн-система и UI/UX спецификация: Salary Tracker

> Зафиксировано на основе ответов пользователя от 14.11.2026. Данный документ является эталонным гайдом по визуальному оформлению и взаимодействиям в приложении.

---

## 1. Общая визуальная концепция и стиль
- **Ключевой стиль:** **Glassmorphism / Frosted Glass** в сочетании с эстетикой современного SaaS (полупрозрачные карточки с `backdrop-blur`, тонкие светящиеся границы `border-white/10`, визуальная глубина).
- **Цветовая тема:** **Адаптивная (System-first)** с автоматической поддержкой Светлой и Тёмной темы (`next-themes`).
- **Характер интерфейса:** Высокотехнологичный, чистый, монохромный с яркими фокусными финансовыми акцентами.
- **Скругления (Border Radius):** Строгие и аккуратные — **`rounded-md` / 4–6px**. Чёткие геометрические контуры, отсутствие избыточной округлости.

---

## 2. Цветовая палитра (Color Palette)

### 2.1. Базовая монохромная гамма (Slate / Linear style)
- **Тёмная тема (Dark Mode):**
  - Background (фон страницы): `#090D16` / `#0B0F19` (глубокий тёмный Slate)
  - Surface / Card (стеклянные подложки): `rgba(15, 23, 42, 0.65)` с эффектом `backdrop-blur-md`
  - Border (границы): `rgba(255, 255, 255, 0.08)` (тонкие светящиеся микро-бордеры)
  - Text Primary: `#F8FAFC` (Slate 50)
  - Text Muted: `#94A3B8` (Slate 400)
- **Светлая тема (Light Mode):**
  - Background: `#F8FAFC` (Slate 50)
  - Surface / Card: `rgba(255, 255, 255, 0.75)` с `backdrop-blur-md`
  - Border: `rgba(226, 232, 240, 0.8)` (Slate 200)
  - Text Primary: `#0F172A` (Slate 900)
  - Text Muted: `#64748B` (Slate 500)

### 2.2. Финансовые акценты (Income vs Expense)
- **Доходы (Income / Success):**
  - Цвет: Изумрудный зелёный (`#10B981` / Emerald 500)
  - Фон подложки / Badge: `rgba(16, 185, 129, 0.12)`
  - Свечение / Glow: `0 0 20px rgba(16, 185, 129, 0.25)`
- **Расходы (Expense / Alert):**
  - Цвет: Насыщенный алый красный (`#EF4444` / Rose-Red 500)
  - Фон подложки / Badge: `rgba(239, 68, 68, 0.12)`
  - Свечение / Glow: `0 0 20px rgba(239, 68, 68, 0.25)`

## 3. Типографика (Typography)
- **Шрифт интерфейса:** `Inter` или `Geist Sans` (нейтральный, легко читаемый гротеск).
- **Шрифт для финансовых сумм и чисел:** `Geist Mono` / `JetBrains Mono` с табличными цифрами (`font-variant-numeric: tabular-nums`) для предотвращения смещения чисел при изменении значений.
- **Иерархия:**
  - H1 / Главный баланс: `text-3xl` / `text-4xl font-bold tracking-tight`
  - Заголовки разделов: `text-xl font-semibold`
  - Метки категорий: `text-sm font-medium`
  - Вспомогательный текст/даты: `text-xs text-muted-foreground`

## 4. UI-компоненты и Glassmorphism спецификация

### 4.1. Стеклянные карточки (Glass Cards)
```css
/* Glass Card Utility */
.glass-panel {
  background: rgba(15, 23, 42, 0.6);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 6px; /* Строгие 6px */
  box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.2);
}
```

### 4.2. Иконки
- Набор: `lucide-react`.
- Размер: 16px (в кнопках и бейджах), 20px (в навигации и категориях), 24px (в карточках KPI).

## 5. Структура экранов и UX-паттерны

### 5.1. Адаптивная навигация (Dual Layout)
- **Десктоп (Desktop ≥ 768px):**
  - Фиксированный стеклянный сайдбар слева (ширина 240px).
  - Ссылки: «Дашборд», «Транзакции», «Категории», «Аналитика», «Настройки».
  - Внизу сайдбара: переключатель темы, кнопка профиля и выход.
- **Мобильные (Mobile < 768px):**
  - Нижняя плавающая стеклянная панель (Floating Bottom Tab Bar) с быстрыми тапами.
  - По центру панели выделенная кнопка быстрого добавления `[+]`.

### 5.2. Главный экран (Dashboard)
1. **Hero-блок (Главный визуальный акцент):**
   - Крупный текущий баланс: например, `145 200 ₽`.
   - Кнопка-глазок «Скрыть/Показать баланс» (по клику заменяет цифры на `••••••` для конфиденциальности в транспорте/кафе).
   - Индикатор дельты за текущий месяц (например, `▲ +12.4% к прошлому месяцу`).
2. **KPI-карточки:**
   - Карточка «Всего доходов за месяц» (зелёный акцент).
   - Карточка «Всего расходов за месяц» (красный акцент).
3. **Графики (Recharts):**
   - Стеклянная карточка с графиком структуры трат (Donut Chart).
   - График динамики расходов по дням.
4. **Лента последних транзакций:**
   - 5 последних операций с возможностью быстрого перехода ко всей истории.

### 5.3. Модуль транзакций и категорий
- Добавление операции: плавный `Dialog` (десктоп) или `Drawer/Sheet` (смартфон).
- Выбор категории с интерактивной палитрой цветов и иконками.
- Фильтры: диапазон дат, табы «Все / Доходы / Расходы», быстрый поиск.

## 6. Анимации и микровзаимодействия (Framer Motion)
- **Уровень динамики: Высокий (Rich Motion).**
- **Переходы между страницами:** Плавное появление со сдвигом по оси Y (`initial: { opacity: 0, y: 8 }, animate: { opacity: 1, y: 0 }`).
- **Анимация чисел (Animated Counter):** Баланс нарастает плавно при первой загрузке.
- **Микроанимации кнопок:** Масштабирование при нажатии (`whileTap: { scale: 0.98 }`, `whileHover: { scale: 1.01 }`).
- **Интерактивные графики:** Плавное раскрытие сегментов круговой диаграммы при ховере.
- **Уведомления:** Всплывающие уведомления `Sonner` со стеклянным стилем.
