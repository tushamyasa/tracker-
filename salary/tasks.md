# План задач: Веб-приложение Salary

> Правило выполнения: За один раз выполняется ровно 1 этап. Переход к следующему этапу — только после подтверждения пользователем. Каждое действие отмечается чекбоксом `[x]`.

- [x] **1.2** Настройка структуры каталогов (`src/app`, `src/components`, `src/lib`, `src/db`, `src/types`, `src/actions`).
